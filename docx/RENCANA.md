# CATATAN RENCANA DAN PROGRES PEMBUATAN WEBSITE

## 1. Identitas Proyek
- **Nama proyek:** Website SMP IT Al-Firdaus Samarinda
- **Jenis:** Website profil dan informasi sekolah
- **Tema desain:** Modern Islamic Academic — Emerald Green
- **Teknologi utama:** HTML, CSS, dan JavaScript Native
- **Status struktur halaman:** 15 dari 15 section selesai (berdasarkan laporan pembuat proyek)

## 2. Latar Belakang dan Tujuan
Website dibuat untuk memperkenalkan SMP IT Al-Firdaus Samarinda secara informatif, menarik, dan mudah diakses. Informasi utama meliputi profil sekolah, keunggulan, dua pilihan pendidikan, kegiatan, fasilitas, PPDB, serta saluran konsultasi bagi calon orang tua/wali dan siswa.

## 3. Sasaran Pengguna
- Calon siswa dan orang tua/wali
- Siswa dan keluarga besar sekolah
- Masyarakat yang mencari informasi sekolah

## 4. Rencana Desain
Mengacu pada dokumen `DESIGN.md`:
- **Warna utama:** Emerald Green `#107C41`, warna pendukung hijau muda `#E8F5EE`, dan latar putih.
- **Tipografi:** Outfit, dengan alternatif font sans-serif.
- **Gaya antarmuka:** Modern, bersih, tombol membulat, kartu informasi, dan hierarki teks jelas.
- **Responsivitas yang direncanakan:** Desktop, tablet, dan ponsel.
- **Aksesibilitas yang direncanakan:** Kontras teks memadai, navigasi keyboard, dan ukuran target sentuh yang nyaman.

## 6. Rencana Fitur dan Interaksi
Berdasarkan spesifikasi desain, fitur yang perlu diperiksa implementasinya antara lain:
- Navigasi halaman dan tombol ajakan bertindak (CTA)
- Perbandingan pilihan pendidikan
- Filter ekstrakurikuler
- FAQ accordion
- Tautan konsultasi WhatsApp
- Efek hover dan focus-visible
- Menu dan tata letak responsive

**Catatan:** Daftar ini berasal dari rencana desain. Fitur yang sudah benar-benar berfungsi perlu dikonfirmasi melalui pengujian website.

## 7. Teknologi dan Ketentuan Lomba
- Gunakan HTML, CSS, dan JavaScript Native sesuai ketentuan.
- Hindari framework/library jika dilarang oleh panitia.
- Simpan kode pada repository GitHub **Public**.
- Publikasikan website agar dapat dibuka melalui URL online.
- Dokumentasikan prompt AI yang benar-benar digunakan selama pengerjaan.
- Pastikan seluruh karya orisinal dan sumber aset sesuai izin penggunaan.

## 8. Tahapan Pengerjaan

2. Menyusun konsep dan spesifikasi desain dalam `DESIGN.md`.
3. Membuat struktur HTML untuk 15 section.
4. Mengatur tampilan dan responsive layout dengan CSS.
5. Menambahkan interaksi dengan JavaScript Native.
6. Menyelesaikan seluruh 15 section. **Status: selesai berdasarkan laporan pembuat.**
7. Menguji seluruh fitur, tautan, dan tampilan di HP serta laptop. **Status: perlu diverifikasi.**
8. Merapikan folder, favicon, dan dokumentasi prompt. **Status: perlu diverifikasi.**
9. Mengunggah repository GitHub Public. **Status: perlu diverifikasi.**
10. Mempublikasikan website dan menguji URL online. **Status: perlu diverifikasi.**
